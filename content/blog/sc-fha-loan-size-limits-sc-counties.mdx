The Federal Housing Administration or **[FHA](/fha-loans/)**, announced the 2019 SC FHA loan size limits in all areas of each state. Most of the SC FHA loan size limits increased to $314,827. But, there are some counties which have higher limits. So make sure that you check these limits when considering an **[FHA](/fha-loans/)** loan. ### FHA Funding Fee

Keep in mind that the [**FHA**](/fha-loans/) funding fee of 1.75% of the loan amount is added on top of the base loan amount. These limits are the base loan only so the [**FHA**](https://portal.hud.gov/hudportal/HUD) funding fee is allowed to be over these limits. In other words, this fee is financed on top of the base loan. So, you don’t have to pay it out of pocket.


Know Your Loan Limits in SC

So if using an FHA loan, check out these limits.  Then compare your approximate loan amount with the corresponding [FHA loan size limits](http://activerain.com/blogsview/4997464/2017-sc-fha-loan-size-limits-by-county).

## 2019 SC FHA Loan Size Limits:

Most SC counties use the standard FHA loan size limits which are shown below. For instance if buying a home in Myrtle Beach with an FHA loan, the maximum FHA loan (before FHA funding fee) is $314,827

-   One-Family Homes = $314,827
-   Two -Family Homes = $403,125
-   Three-Family Homes = $487,250
-   Four-Family Homes = $605,525
